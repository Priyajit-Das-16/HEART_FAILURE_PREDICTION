# Heart Failure Prediction Using Machine Learning

## Project Overview
This project uses machine learning techniques to predict patient mortality based on clinical records. It focuses on exploring relationships between patient attributes and mortality outcomes and developing a classification model to support predictive analysis.

## Objectives
- Explore clinical data to identify patterns associated with patient mortality.
- Understand relationships between patient attributes and the target variable.
- Build a machine learning classification model.
- Evaluate model performance using appropriate classification metrics.

## Dataset
The project uses a clinical dataset containing patient health-related attributes and a target variable indicating the mortality outcome.

## Tools & Technologies
- **Programming:** Python
- **Libraries:** Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn
- **Environment:** Jupyter Notebook

## Project Workflow

### 1. Data Loading and Preprocessing
- Loaded and examined the clinical dataset.
- Inspected data types, missing values, and basic statistical properties.
- Prepared the data for exploratory analysis and model development.

### 2. Exploratory Data Analysis (EDA)
- Analyzed the distribution of clinical attributes.
- Investigated relationships between patient characteristics and mortality.
- Used statistical summaries and visualizations to understand the dataset.

### 3. Model Development
- Developed a Logistic Regression classification model.
- Used patient clinical attributes as input features to predict mortality outcomes.

### 4. Model Evaluation
- Evaluated the model using a test dataset.
- Achieved **84% test accuracy**.
- Examined classification performance to understand the model's predictive ability.

## Key Skills Demonstrated
- Data Preprocessing
- Exploratory Data Analysis
- Logistic Regression
- Classification
- Model Evaluation
- Statistical Analysis
- Python and Scikit-learn

## Repository Structure
- `*.ipynb` – Data analysis, model development, and evaluation notebook
- `*.csv` – Dataset file

## Conclusion
This project demonstrates the application of machine learning to clinical data for mortality prediction. It provided practical experience in exploratory data analysis, classification model development, and model evaluation.
